Your agents keep leaking.

A memory census and pressure guard for the agent-era Mac. It reaps orphaned MCP servers, closes idle sessions, and warns before the OOM dialog picks for you. One file. Zero deps.

Get the script Usage

MIT. 32 KB on disk. 3.4 MB for 0.14s every two minutes, then nothing resident.

First 48 hours, 16 GB M4

41 orphaned MCP trees reaped. Swap 91% → 55%. Zero wrongful kills. No force-quit dialogs that day.

Classic cleaners see 60 anonymous node processes and stop there. memscope knows what an MCP connector is.
  1. 1
    Census by family.

    Chrome, Electron, node agents, Java, Python, databases. Who actually eats what.

  2. 2
    Reap the dead ones.

    Sessions that died and left connectors on launchd. Prints kill lines. Guard can do it for you.

  3. 3
    Warn before OOM.

    Under pressure it names the biggest tabs and apps. Idle Claude sessions can auto-close. Nothing with user state is killed.
