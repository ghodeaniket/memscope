The more agents you run, the less Mac you’re left with.

Agentic development scales sideways. Every session spawns its own fleet of tool servers, connectors, and headless browsers. The sessions end. The fleets don’t.

By midweek the machine is sand. macOS starts force-quitting on its own judgment — and it doesn’t kill politely. It kills the thread you were working in: the session holding three hours of context, the agent mid-migration, the reasoning you can’t re-prompt.

$ ./memscope.sh guard --dry-run
41 orphaned agent-tool trees · parent: launchd · age: up to 3 days
pinning ~4 GB of swap · invisible to Activity Monitor (named node)
→ would reap all 41 · live sessions untouched

What’s going on

You scale the workflow: more agents, more subagents, more tools. Each session is a process fleet. Fleet size × open sessions is the real footprint.

Sessions end. Children get orphaned and idle forever. RAM fills with finished work, swap grows to hold it, and every click pays a paging tax. It reads as “my Mac is old.” It isn’t.

At the ceiling, macOS picks victims. The beachball is annoying. Losing state is expensive.

Two fixes. One costs a couple of thousand dollars.

A 64 GB machine genuinely solves it. A lot of that money buys headroom for processes that finished their work days ago.

So run the script first. The dry-run is read-only and takes five seconds. If memscope finds nothing, buy the laptop with a clear conscience — the new RAM will go to live work, not ghosts.

This page exists because that first pass found 4 GB of ghosts, and the upgrade stayed in the cart.

The census, then the guard

  • Reap the provably dead. Tool trees whose session is gone — parented by launchd, older than 2 hours — are killed. Nothing with a living parent is touched.
  • Close the abandoned. A session with zero CPU for six straight hours is unread. Graceful TERM, transcripts stay on disk.
  • Warn before macOS picks victims. Under pressure it names the actual consumers while you can still choose.

The kill-list is exactly two provable classes: dead fleets and 6-hour zero-CPU sessions. Everything else is advice. Dry-run shows every intended kill before you grant it anything.

See your ghosts in five seconds

git clone https://github.com/ghodeaniket/memscope && cd memscope
./memscope.sh                 # census
./memscope.sh guard --dry-run # your orphan list
./memscope.sh install-guard   # every 2 minutes
